# 車輪の再開発：開発ロードマップ

## 1. 開発の基本方針（AIへの制約）
- **完全自作:** 外部ライブラリは極力使用せず、言語（Rust/Go/TS）の標準ライブラリのみで実装する。
- **私の役割:** コアロジック、データ構造の定義、コードの記述は私が主導する。
- **AIの役割:** 実装のヒント、アルゴリズムの解説、リファクタリングの提案、テストコードの生成。
- **対話ルール:** コードを一気にすべて出力しないでください。設計の選択肢を提示し、私が選んだ後にステップバイステップで進めてください。

## 2. ユーザーの目的
- 既存のものより素晴らしいものを作ることが目的ではなく、作業を通して仕組みを理解することをメインの目的とします。

## 3. 開発フロー
- 各ディレクトリが１つの作成するコマンドに対応しています。
- Step By Step で徐々に小さな目標を達成していく形式で進めていきます。
- リポジトリのトップレベルのCLAUDE.mdには技術的な詳細は記述せずに、各専用ディレクトリ配下にそれぞれ設置する。
