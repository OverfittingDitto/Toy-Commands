# my-pwd

`pwd` (print working directory) コマンドの自作。

## 学習ゴール
- カレントディレクトリを取得する仕組みを理解する
- Rust 標準ライブラリ（`std::env`）の使い方を学ぶ
- 終了コード・標準出力/標準エラーの扱いを学ぶ

## 制約
- 外部 crate は使わず、標準ライブラリのみで実装する
- コアロジックはユーザーが主導して書く
- AI は一気にコードを出さず、設計の選択肢を提示 → ユーザーが選択 → ステップバイステップで進める

## 本家 pwd の主な仕様（段階的に実装していく対象）
- 引数なし: カレントディレクトリの絶対パスを1行で出力
- `-L` (logical): 環境変数 `PWD` を尊重（シンボリックリンクを解決しない）※デフォルト
- `-P` (physical): シンボリックリンクを解決した実体パスを出力
- `--help` / `--version`

## 進め方（小さな目標の例）
1. カレントディレクトリを取得して出力するだけの最小版
2. 取得失敗時のエラーハンドリングと終了コード
3. `-P` / `-L` オプションの分岐
4. `--help` / `--version`

## 実行
```sh
cargo run            # my-pwd を実行
cargo run -- -P      # 引数を渡す場合は -- の後ろ
```
